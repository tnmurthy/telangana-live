# Vercel Production Deployment Guide for Telangana.live

This document outlines the strict directory architecture and configuration files needed to deploy your custom HTML/JS site on Vercel while keeping your AdSense and Search Console assets public at the root path (`/`).

---

## Part 1: Mandatory Vercel Project Directory Structure

Vercel serves static files out of the project root directory by default, unless configured otherwise. To prevent routing conflicts, organize your files exactly like this before running a deployment:

```text
telangana-live-project/
├── index.html
├── privacy-policy.html
├── ads.txt
├── google123456789.html  <- (Your Search Console Verification File)
├── vercel.json           <- (Configuration file for header rules)
├── js/
│   └── main.js
└── css/
    └── style.css
```

---

## Part 2: Custom Headers Configuration (`vercel.json`)

To ensure Google's web scrapers can crawl your `ads.txt` and HTML verification tags without running into caching or CORS blockages, create a file named exactly `vercel.json` in your root folder and paste this code:

```json
{
  "version": 2,
  "cleanUrls": true,
  "headers": [
    {
      "source": "/ads.txt",
      "headers": [
        {
          "key": "Content-Type",
          "value": "text/plain; charset=utf-8"
        },
        {
          "key": "Cache-Control",
          "value": "no-cache, no-store, must-revalidate"
        }
      ]
    }
  ]
}
```

---

## Part 3: Deploying via Vercel CLI (Step-by-Step)

If you are deploying directly from your local terminal instead of a connected GitHub repository, follow these precise commands:

1. Open your terminal inside your project folder (`telangana-live-project`).
2. Install the Vercel command line interface globally if you haven't already:
   ```bash
   npm install -g vercel
   ```
3. Log in to your Vercel account:
   ```bash
   vercel login
   ```
4. Push your site to production to generate live URLs:
   ```bash
   vercel --prod
   ```

---

## Part 4: Production Verification Checklist

Once Vercel gives you the live confirmation link, open your web browser and immediately verify these four live URLs to guarantee Google AdSense compliance:

* **Site Index**: `https://telangana.live` (Must load your main UI with the AdSense `<script>` tag active in the view-source HTML head).
* **Console File**: `https://telangana.livegoogle123456789.html` (Must return the code string string generated by your Search Console dashboard).
* **Ad Inventory**: `https://telangana.liveads.txt` (Must output your single raw `google.com, pub-XXXX...` text line cleanly without any HTML structural wrapping).
* **Privacy Compliance**: `https://telangana.liveprivacy-policy` (Must resolve perfectly as a clean, indexable layout via Vercel's cleanUrls routing rule).
